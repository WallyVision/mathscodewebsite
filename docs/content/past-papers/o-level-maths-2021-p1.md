## Q1 · difficulty 1

**Stem**

Given the set of real numbers $\mathbb{R}$, the identity element for multiplication is

**Options**

- A. $1$
- B. $0$
- C. $-1$
- D. $2$

**Correct:** A

**Solution**

The identity element leaves every number unchanged: $a \times 1 = 1 \times a = a$. So it is 1.

**Answer: A**

0 is the identity for **addition** ($a + 0 = a$).

## Q3 · difficulty 2

**Stem**

Simplifying $\frac{2}{3} + \frac{1}{4} \div \frac{3}{5}$ gives

**Options**

- A. $\frac{5}{7}$
- B. $\frac{11}{20}$
- C. $\frac{13}{12}$
- D. $\frac{55}{36}$

**Correct:** C

**Solution**

By BODMAS, divide before adding:

$$
\frac{1}{4} \div \frac{3}{5} = \frac{1}{4} \times \frac{5}{3} = \frac{5}{12}
$$

$$
\frac{2}{3} + \frac{5}{12} = \frac{8}{12} + \frac{5}{12} = \frac{13}{12}
$$

**Answer: C**

Option D adds first and then divides, which breaks the order of operations.

The functions $f$ and $g$ are defined on $\mathbb{R}$, the set of real numbers, by $f : x \mapsto x + 2$ and $g : x \mapsto 1 - 4x$. $fg(x)$ is

**Correct:** C

**Solution**
