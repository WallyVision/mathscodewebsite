## Adding them

**If the questions are already on the site:** open each question in **Admin → Questions**,
use **Add a diagram or picture** to upload its file, and paste the line it gives on a new line
at the end of the question text. Save.

**If you have not imported the set yet:** upload all thirteen files first (**Admin → Images**),
paste each line at the end of the matching question's **Stem** in the question file, then
import the file as usual.

The question text still states every fact in words, so each question also works without its
picture.
