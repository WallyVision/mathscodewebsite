## Adding them

**If the questions are already on the site:** open each question in **Admin → Questions**,
use **Add a diagram or picture** to upload its file, and paste the line it gives on a new line
at the end of the question text, below the description of the figure. Save.

**If you have not imported Q11–50 yet:** upload both files first (**Admin → Images**), paste
each line at the end of the matching question's **Stem** in the question file, then import the
file as usual.

The question text still describes each figure in words, so both questions also work without
their pictures.
